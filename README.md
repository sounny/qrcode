# Sounny's QR Code Maker

A personal, single-file web app for creating QR codes. The entire application lives in `index.html`, making it easy to host on services like GitHub Pages.

## Features
- Generate QR codes from text or URLs
- Customize size, colors, and error correction
- Add a logo and download or copy the result

## Usage
Open `index.html` in any modern browser or publish the file via GitHub Pages.

## Development
This project has no build step. Edit `index.html` and open it in a browser to see changes.
